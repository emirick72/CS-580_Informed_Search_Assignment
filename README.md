# Informed Search Assignment

Note: The user must have Python already installed on their local machine in order for this program script to run.

This assignment is a program that creates two heuristic search algorithms that find solutions to the 24-puzzle problem. I first started with the 8-puzzle problem, then adjusted the program to the 24-puzzle problem.

Author's Note: There is a possibility that this program might crash due to my machine not having enough RAM to solve the 24-puzzle problem. I am planning on hard-coding a RAM guardrail that maxes out how much RAM the program is allowed to use. (I am aware that this guardrail will not allow the program to solve the problem all the way or as intended. This guardrail is specifically being put in the program so my PC doesn't break, as it's specs does not have the amount of resources needed for this program.)
